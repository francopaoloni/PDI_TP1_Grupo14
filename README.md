Trabajo Práctico N° 1 — Procesamiento de Imágenes I

| Archivo | Descripción |
|---|---|
| `problema1.py` | Problema 1 — Ecualización local de histograma. |

## Requisitos

- **Python** 3.12.10

| Librería | Versión |
|---|---|
| opencv-python | 5.0.0.93 |
| numpy | 2.5.3 |
| matplotlib | 3.11.2 |

### Instalación

```bash
pip install opencv-python==5.0.0.93 numpy==2.5.3 matplotlib==3.11.2
```

## Ejecución

> **Importante:** los scripts leen las imágenes con rutas relativas, por lo que deben
> ejecutarse desde la carpeta del repositorio. Ahí mismo agregar las imágenes que serán procesadas.

### Problema 1 — Ecualización local de histograma

```bash
python problema1.py
```

### Problema 2 — Validación de planillas de calificaciones

```bash
python problema2.py
```
